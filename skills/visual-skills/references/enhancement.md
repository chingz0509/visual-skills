# 创意改造：实际生图与导入

适用于用户已选择允许主体变化的任务。先看图，记录允许改变的材质、光影、背景、姿势等范围，以及必须保持的脸、毛色、人数、关键物品/商标/结构。无额外授权时，允许风格变化不意味着允许换人、删人、换产品或伪造品牌事实。

## 工具选择

优先调用用户宿主的实际图像编辑工具，以原照片为图像输入；仅把图片写成文字描述不是图像编辑。也可使用用户明确选用且已配置的服务。技能不携带作者的代理地址、密钥、本机环境文件或共享额度。生成可能向所用服务发送原图，沿用用户对该工具的授权和隐私设置。

无图像工具时说明创意模式不可用，给出原片拼贴选项。不要把本地加颗粒称为 AI 重绘，不伪造模型输出。尺寸按工具能力请求 1200×1600；不支持时选择同为 3:4 的尺寸并等比缩放到交付尺寸，不把方图拉长。宿主用户明确要求其他生成尺寸时遵循其要求，并说明需重新构图才能交付 3:4。

## 设计输入

提示词描述 **一个主体焦点 + 一组主标题 + 明确的字图空间关系 + 两三种有作用的材料**。主体允许的改变与必须保留的特征写清楚。文字逐字列出；实际图像质量由成品检查决定。

可选择的方向（例子是设计语法，不是必须照抄的内容）：

- 人像：黑白网点剪贴与钴蓝色块，偏置主体，短大字沿轮廓排布。
- 宠物：暖色印刷剪影与不规则浅色纸场，标题和主体有不同重心。
- 产品：保留关键结构和标识，强光影/双色印刷，留大块文字负空间。
- 合照/风景：维持主体数量与原有关系，使用整张照片、跨页或叠页关系。

避免每张都用相同网格纸、白边、星星与底部黄条。变体要改变构图语法，而非只换底色。不要复制参考项目样张、标志或完整设计。

## 导入真实生成结果

把实际提示词和参数保存为 `generation-input.json`，它不包含服务密钥或请求头：

```json
{
  "permission": "user_selected_creative",
  "model": "实际调用的模型或工具名称",
  "prompt": "实际使用的完整提示词",
  "parameters": {"size": "1200x1600", "quality": "high", "output_format": "png"}
}
```

计划指定 `subject_policy: creative`、`layout: freeform`、`photo_mode: whole`，填写 `allowed_changes` 和 `keep_features`。执行：

```bash
python scripts/run.py render --input /path/to/original.jpg --plan /path/to/plan.json --output /path/to/new-run --artwork /path/to/actual-generated.png --provenance /path/to/generation-input.json
```

修复同理向 `repair` 传入新的 `--artwork` 与 `--provenance`。第二次修复由程序回退原片，无需再生图。

成品按 [验收](review.md) 检查。只通过尺寸、文件检查不能交付成功；AI 文字错、手脚多、脸换人、产品结构错都应拒绝。真实生成图是一个平面图层，内部纸片和字体不是可单独编辑图层；保存它可逐像素复现成品，保存提示词不保证再次生成相同结果。

# 摄影剪贴的设计判断

目标是参考独立音乐海报、杂志剪贴和档案拼贴的语法：主体清楚、标题有设计、照片和纸层有前后关系，印刷质感统一。先决定一个视觉焦点与阅读顺序，再选材料。

## 构图选择

| layout | 字图关系 | 使用方式 |
|---|---|---|
| cover | 左上大标题，主体偏右下进入纸场，题注独立 | 可抠图也可整图；适合人物、宠物、物品 |
| split | 左侧标题栏与右侧高幅主体分工 | 1–3 行短标题；适合竖向轮廓，合照勿挤小 |
| window | 完整横向照片在上，文字形成下方主块 | 适合风景、宽合照、环境照片；保留边界 |
| freeform | 依据照片自由安排轮廓、留白和文字 | 创意模式：实际模型出图后导入，不能用于原片保真承诺 |
| cutout/editorial/landscape | 旧版的居中剪影、照片叠层、风景纸框 | 兼容旧计划，非新版优先推荐 |
| simple | 完整原片与简洁题注 | 最后一轮修复的降级布局 |

布局与模式分开：`cover` 不要求一定抠图；合照、风景的本地渲染始终保持整图。毛发、透明件或首饰分割不可靠时选择整图，不能用加厚白边掩盖损伤。

## 让设计成立

- **标题**：根据照片拟短句，以字号、行长、对齐构成主次。缩略图能读主标题。正式信息保持完整；英文只在增强主题时使用，不为填空硬加口号。
- **主体**：放大到能看清表情、轮廓或产品特征。小合照不要压进侧栏。人脸、关键物品不放在文字、胶带下面。
- **材料**：挑有作用的两三种。色纸建立重心、撕边建立照片与纸的关系、胶带表现固定方式。装饰不承担主体缺失的补救作用。
- **质感**：浅接触阴影、缓慢起伏的纸色、纤维边和克制网点。纸张有触感，脸和产品细节仍可辨识。避免厚重浮雕和一层噪点掩盖所有层次。
- **变化**：连续案例改变至少一个主要字图关系。比如大字封面、侧栏与主体、照片跨页；同一模板换三种颜色不能代表三种设计。

本地配色 `cobalt`（暖白/钴蓝/朱红）、`tomato`（番茄红/浅黄/淡紫）扩充旧的 `lilac/lagoon/archive/forest`。根据照片与情绪选，避免每类机械固定一种。产品关键色与标识在原片模式保持；创意改变应在用户允许范围内。

## GitHub 参考与边界

- [Bright Paper Collage](https://github.com/dse120071750/paper-collage-design-skill)：参考把构图、材料、字体和节奏分开决策的方式。
- [GC Minimal Zine](https://github.com/LiamGvchi/gc-minimal-zine-poster)：参考一个焦点、缩略图筛选和不同构图语法；其大比例留白不是本风格的统一要求。
- [Paper Collage Edit](https://github.com/ducdg88/paper-collage-edit)：参考可运行的纸边、纹理和浅阴影思路。

本项目重新实现上述设计原则，没有搬运第三方源码或案例图片。各项目的示例图许可不必然等同代码许可。

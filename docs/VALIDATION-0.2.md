# 0.2.0-preview 验证与限制

2026-11-09。用户认可本轮展示方向并授权发布；这不是完整固定集或所有场景的最终验收。

| 本轮开发案例 | 主体模式 | Agent 检查结果 |
|---|---|---|
| 人像封面 / cover | 原片 | 复杂通过 |
| 相机侧栏 / split | 原片 | 复杂通过 |
| 风景照片 / window | 原片 | 复杂通过 |
| 人像自由拼贴 | 创意 | 复杂通过 |
| 幼猫自由拼贴 | 创意 | 复杂通过 |
| 相机自由拼贴 | 创意后退回原片 | 最终失败：两次生成改变转盘刻度，最后简洁版主体过小、构图不足 |

只对这些开发预览做了检查，没有重跑完整十张，不发布新版成功率。旧十张和冻结输入没有替换。通过的五个预览验证了保存图层的逐像素重合成。

新增 12 项程序行为测试全部通过，涵盖原片保留、创意导入、额外主体检查、尺寸拒绝、三次预算、恢复原片、图层复现和公开打包。技能结构校验、隐私扫描、安装包解压运行也通过。程序检查不能代替实际看图或用户判断。

公开展示两张来自固定集的实际 AI 编辑，输入照片许可沿用 [素材来源](../THIRD_PARTY.md)。实际提示词和模型信息在 [案例目录](../examples/v0.2.0-preview/)。原图、运行缓存、原始 OCR、服务配置、个人路径和完整图层包不公开。

创意图像使用宿主可调用的工具或用户自己配置的服务，可能产生费用并将图片发送到该服务。项目不提供共享密钥或作者额度；没有生图能力时仍可使用原片模式。

AI 整图是平面素材，不承诺内部纸片、字体分层编辑。身份、毛发、手脚、产品细节和文字仍可能生成错误，需实际检查；重新生图不保证相同输出。

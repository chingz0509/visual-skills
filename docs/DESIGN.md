# 首版设计约定 · 2026-11-03

> 2026-11-09 变更：用户反馈旧输出不满意，允许按用户选择进行主体创意改造。当前入口提供 `preserve/creative` 两种模式，后者记录允许改变与必须保留的特征，不承诺像素保真。下文是旧版原片模式的设计与实验约定；旧十张保留，新模式单独验证。当前行为以 skill 入口及其 references 为准。

目标用户是已在使用 Agent 的人。安装一个风格 skill、给一张图片，自动获得中文优先的海报；技术准备由 Agent 和脚本承担。首个完整验证目标是用户当前的 Codex 桌面端，其他 Agent 按通用 skill 结构逐步验证。

## 产品承诺

- 先发布一个摄影剪贴拼贴风格；价值是识图、主体保留、设计执行、检查与有限修复的稳定流程，以筛选过的风格和完整案例展示。
- 单人、多人、产品、宠物、风景五类。用户不给文案时自动决定短句、配色和构图；不编造姓名、活动、日期、地点或背书。
- 主体内部细节不重绘。合照不删人、不拆散关系；风景保持整张照片及关键内容；产品和宠物保持完整主要主体。
- 默认 3:4 竖版，照片放进版式，必要时保留完整照片边界。允许黑白和轻微印刷感。
- 首版主要审美来源是用户参考图 1、4、7 的设计语法：主次、纸张与照片叠层、标题设计、统一印刷质感。参考图不随包分发，也不直接抽取其素材。
- 基础流程不强制生图。Agent 使用用户自己的宿主模型；本地合成工具不需要作者服务器或共享密钥。生图仅作为后续可选装饰增强。

## 分工与输出

Agent 看图、选择设计、做视觉检查；本地程序保留原片、抠图、排字、生成程序纹理、合成并验证硬指标。这里的“程序”随 skill 一起安装，由 Agent 自动运行。

输出 PNG + 实际素材、布局、字体、计划和检查记录。保存后的图层可精确重合成；重新调用模型不保证相同。用户不需要 PSD 才能使用，首版也不承诺交付可编辑 PSD。

## 失败流程

初次复杂拼贴 → 第一次修复 → 第二次改用完整原图的简洁拼贴 → 再检查 → 通过或失败。总共最多三次尝试。复杂不是装饰多；完整照片同样可以组成复杂拼贴。结果区分复杂通过、简洁通过、失败。

程序做硬检查，Agent 做视觉检查，项目发起人做首版最终验收。优先完成流程，接受等待。先以实验项目公开，不宣称已经达到普遍可用标准。

## 固定验证

五类各两张、一易一难；调试前冻结输入 ID、文件哈希、难点。不得因失败换图。目标至少 8/10 可直接用，其中至少 6/10 复杂通过；主体改坏一律失败。完整公开成功、降级、失败及中间尝试。

固定集是开发验证，不是独立盲测。报告必须区分程序检查、Agent 初检、用户最终验收。元数据发现错误时用补充文件更正，不变更冻结输入或抹去记录。

## 已知取舍

首版采用 Python/Pillow 合成，Apple Vision 提供本地 alpha 分割与 OCR。缺少分割时仍能整图拼贴；跨系统运行尚待验证。每个风格先自包含，第二个风格出现真实复用需求后再抽取共享包，避免小白安装单个 skill 时漏掉外部依赖。

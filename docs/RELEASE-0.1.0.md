# Visual Style Skills 0.1.0-experimental

首个实验版本：在 Agent 中把照片做成摄影剪贴拼贴海报，保留原片主体，自动安排标题、配色和纸张叠层。

## 下载选择

- `photo-paper-collage-0.1.0-experimental.zip`：使用者下载，内含完整 skill、脚本、字体和说明。
- `visual-style-skills-0.1.0-experimental.zip`：开发者下载，另含案例、测试和贡献说明。
- `SHA256SUMS.json`：以上文件的校验值。

解压独立 skill 包，把目录交给 Codex 并说“请安装这个摄影剪贴拼贴 skill，并准备运行环境”。之后上传照片，说“用摄影剪贴拼贴做一张海报”。基础流程不需要生图密钥。

## 当前证据

固定 10 张开发测试图片，8 张初次通过作者 Agent 检查，2 张宠物图在恢复完整原片后通过。全部中间结果与检查记录在仓库 `benchmark/REPORT.md` 展示。10 个最终输出均可逐像素重合成，6 项行为测试本地通过。

## 已知限制

用户最终验收待完成；开发集成绩不代表通用成功率。仅在当前 Codex 桌面端和 Apple Silicon macOS 环境完成开发验证，全新机器安装和其他宿主待验证。布局固定 3:4，四种版式、四套配色，支持短文案；细毛抠图和版式多样性仍需改进。可选生图增强尚未接入。

欢迎通过 Issue 反馈安装环境、失败原因与经授权公开的样例。新增风格请先阅读 `CONTRIBUTING.md`。代码 MIT；照片与字体遵循各自许可。

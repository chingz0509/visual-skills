# 使用与运行说明

[返回首页](../README.md)

## 安装包是什么

只需一个 `visual-skills` 安装 ZIP，解压后将其中同名文件夹交给 Agent 安装。该目录内的 `SKILL.md` 是入口，脚本、字体和规则已包含。GitHub 的 Source code 是开发源码，不是另一个必装组件。当前开发打包为 `0.2.0-preview`；旧 `0.1.0-experimental` Release 不包含新版创意流程。

首次运行可能下载 Pillow、NumPy 等依赖；有可用环境时直接复用。照片合成在本地进行，但宿主 Agent 为了看图可能处理上传图片，请以所用 Agent 的设置为准。

## 本地安装

在仓库目录运行 `python3 scripts/install.py --prepare`，安装到 Codex skills 目录。同名安装不会被覆盖。若技能列表未刷新，新开对话或让 Agent 读取安装后的 `SKILL.md`。

## 什么叫本地程序

它是跟 skill 一起提供的小工具，Agent 自动调用，用户不用学写程序或操作设计软件。原片模式由工具抠图、摆放照片、排字、绘制纸张和导出 PNG；创意模式由宿主图像工具实际改图，本地工具保存并检查交付尺寸、素材和记录。模式选择后会说明主体是否被重绘。

- **聊天与视觉判断**：用用户正在使用的 Agent。
- **基础设计合成**：用户环境里的本地程序，无额外生图费用或作者服务器。
- **创意改造**：用用户宿主可调用的图像工具或用户自己的服务处理主体和版面，保存实际生成图和提示词；没有图像工具时提供原片模式。

## 支持范围

首个验证环境为 Codex 桌面端、Apple Silicon macOS 26.6.1。依赖准备会优先复用宿主可用的 Python；缺包时创建隔离环境。

macOS 14+ 且具备 Swift 命令行工具时，可用 Apple Vision 本地前景分割和 OCR。缺少分割工具时采用完整照片的复杂拼贴，不会要求生图密钥。安装、网络或宿主权限仍可能阻止自动准备；此时如实说明。Windows、Linux 和其他 Agent 尚未完整验收，不宣称跨平台开箱即用。

支持单人、合照、产品、宠物和风景。原片模式的合照与风景保留完整照片，抠图不可靠时改为整图。新增三种本地构图与两组配色，创意模式支持自由构图。短文案、分割细节、生成文字和模型改图质量仍是局限，新版正在验证。

## 输出和修复

每个任务保存原图、计划、三次以内的尝试、照片处理说明、图层、字体、检查、视觉意见、复现脚本与最终 PNG。

创意整图的内部纸片和文字不是独立图层；保存的是实际生成的平面图、提示词、参数与原片。必须选择允许改变的范围，并检查辨识度、肢体与关键物品。无论模式，程序通过均不能替代看图。生成服务可能接收原图，请遵循所用宿主和服务的设置。

初次复杂拼贴 → 第一次修复 → 第二次使用完整原图的简洁拼贴 → 通过或失败。硬检查通过后仍需 Agent 实际看图。没有视觉检查的作品不算通过。

使用 bootstrap 返回的 Python 运行：

```bash
python scripts/replay.py /path/to/attempt-0 --output /path/to/replayed.png
```

这里的 `scripts/replay.py` 位于已安装 skill 内；也可使用输出包自带的 `replay.py`。已保存的图层可以逐像素重合成；重新调用模型不承诺同图。
